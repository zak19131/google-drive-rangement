# Checklist hebdomadaire — 10 minutes, le dimanche

- [ ] **Racine** : aucun fichier en vrac (tout ce qui traîne va dans 00_INBOX).
- [ ] **00_INBOX** : chaque élément est classé ou renommé selon la convention. Objectif : 0, seuil d'alerte à 20.
- [ ] **Doublons** : pas de fichier `(1)`, `Copie`, `final` créé dans la semaine.
- [ ] **Nommage** : les nouveaux fichiers respectent `AAAA-MM-JJ_NATURE_Sujet_vN`.
- [ ] **Partages** : aucun lien public sur 01_ADMIN, 02_FINANCE, RH_Paie (Drive → clic droit → Partager).
- [ ] **99_CORBEILLE** : les éléments de plus de 30 jours sont listés et validés pour suppression définitive, ou restaurés.
- [ ] **Mensuel (1er dimanche)** : relancer l'audit (`scripts/weekly_check.sh` sur un export frais) et archiver les projets clos dans 08_ARCHIVES.
